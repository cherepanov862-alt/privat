# Севермакс — управление подогревателем по SMS

Приложение отправляет SMS-команды из инструкции подогревателя Севермакс 5000 mini
и разбирает ответы (HEATER ON/OFF, XHPZ OK, UP/DOWN TEM, CSQ, коды E-01…E-12).

## Как получить APK без Android Studio
1. Создайте репозиторий на github.com и загрузите в него содержимое этой папки.
2. Откройте вкладку Actions → Build APK → дождитесь зелёной галочки.
3. Внутри запуска скачайте артефакт severmax-control-apk, распакуйте и установите app-debug.apk.

## Через Android Studio
File → Open → выберите эту папку → Build → Build APK(s).

## Первый запуск
1. Разрешите отправку и приём SMS.
   На Android 13+ для установленного вручную APK может понадобиться:
   Настройки → Приложения → Севермакс → ⋮ → «Разрешить ограниченные настройки».
2. Вкладка «Настройки»: введите номер SIM подогревателя, выберите NFPZ или CGPZ.
3. Привяжите телефон в слот 1 (SMS TJSQ*123456*A).
